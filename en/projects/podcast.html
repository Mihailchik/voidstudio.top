Podcast Bot

Podcasts from different sources in one channel.

Code on GitHub ↗︎

What it is

Podcast Bot gathers podcasts from different places into one Telegram channel. It watches the sources by itself, downloads new episodes and sends them in a form that is easy to listen to.

How it works

01

Three kinds of sources

RSS feeds, YouTube channels and playlists, and Telegram channels.

02

Scheduled checks

The bot checks the sources and picks up new episodes by itself; no one has to do it.

03

Two versions

Every episode is converted to MP3 and sent in two versions: normal and double speed.

04

Large files

Files that are too large are split into parts before sending.

05

Links from people

You can send the bot a link and it will queue it for processing.

Built with: Python · aiogram · yt-dlp · ffmpeg · SQLite
