Eyeball

Five tasks done by eye. One attempt a day.

Play ↗︎Code on GitHub ↗︎

What it is

Eyeball is a daily mini-game that tests how accurate your eye is. Put the ruler away. The game opens from a link and takes a couple of minutes.

How it works

01

Five tasks

Stop a timer blind, mark a share of a line, set an angle, find the centre of a circle and estimate a number of dots.

02

The same for everyone

The set is new every day and the same for every player, so there is someone to compare your result with.

03

A score and a grid

You finish with a score out of 100 and an emoji grid to share.

04

No server

There is no sign-up and no server. Progress is kept in the browser.

Built with: Vanilla JS · SVG · localStorage
