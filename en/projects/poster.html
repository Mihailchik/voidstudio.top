Poster 2.0

One release for several platforms.

Poster 2.0 stores ideas and media, prepares formats for Telegram, Instagram, YouTube and Pikabu, validates files, schedules publications and records the result. It runs the Void Studio content workflow.

How it works

01

Content

An idea, a text and source media go into the system. Every project has its own profile: topic, language, platforms and schedule.

02

Formats

One release becomes images and video in the right sizes, with captions for each platform. This step runs on templates, with no AI.

03

Validation

Finished files are checked automatically before they reach the schedule.

04

Human approval

Before a release goes out, an admin gets a preview and decides whether to publish. Nothing goes out without approval.

05

Publishing and records

At the set time the system publishes the release and records what went out and with what result.

Built with: Python · SQLite · Docker · Telegram API
