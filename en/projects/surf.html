Surf

Is it worth going surfing right now?

Open Surf ↗︎Code on GitHub ↗︎

What it is

To know whether there are waves today you have to open several weather sites and compare charts. Surf answers one question: is it worth going now, and to which beach. Waves, wind, tide and beach cameras for Phuket and Khao Lak sit on one page.

How it works

01

A score from 0 to 10

Every hour at every beach gets a number and a word, from flat to epic. The score is rounded down so a beach is never worse than promised.

02

Several models

Data from Open-Meteo, MET Norway and NOAA is combined into a median. The spread between sources shows how far the forecast can be trusted.

03

No server

It is a single static page. Data is loaded straight in the browser, with no sign-up and no keys.

04

Forecast history

Every morning the site records what the forecast promised and what the models show for the day that passed. This makes it clear where the forecast is wrong.

05

Three languages

The interface is in English, Russian and Thai.

Built with: Vanilla JS · Open-Meteo · MET Norway · NOAA · GitHub Pages
