# Void Studio — наполнение перед публикацией

Обновлено: 10 сентября 2026.

## Что сайт должен сообщить за первые 15 секунд

Void Studio создаёт цифровые продукты и визуальные эксперименты: от изображения и движения до работающего сайта, приложения, бота или автоматизированной системы. Посетитель может посмотреть реальные проекты и написать по новой задаче.

## Структура

1. Главная: интерактивная лента визуальных работ и вход в содержательную часть сайта.
2. Проекты: Inkfall, Surf, Poster 2.0, Argyns, Podcast Bot.
3. Работы: интерактивная лента из выбранных изображений и видео Void Studio.
4. О студии и контакт: короткое позиционирование Void Studio, Telegram как основной путь обращения, социальные площадки в подвале.

## Материалы, которые нужно выбрать

### Минимум для запуска

- 7–10 визуальных работ для тёмной ленты. Исходники максимального качества, без интерфейса соцсетей, подписей и водяных знаков. Для первого запуска ленты используем изображения; видео показываем внутри проектов.
- Inkfall: ролик экрана 8–12 секунд, 16:10 или 16:9, 1440p. Один непрерывный красивый жест курсором; интерфейс можно скрыть через `?bare=1`. Дополнительно один стоп-кадр 1600 × 1000 для слабых устройств.
- Surf: ролик экрана 8–12 секунд, 16:10 или 16:9, 1440p. Показать выбор пляжа, оценку ближайших часов и одну камеру. Не записывать длинный скролл всей страницы.
- Poster 2.0: 3 скриншота одного сценария: идея → готовые форматы → расписание/результат. Скрыть токены, ID чатов, личные имена и служебные адреса. Альтернатива — ролик 10–15 секунд.
- Argyns: 3 вертикальных скриншота телефона: главный экран, выбор/статистика рода, уведомления или регистрация города. Желательно одинаковое устройство и размер.

### Можно добавить после запуска

- 1–2 фотографии среды студии: руки, ноутбук, планшет, съёмка, вода или дорога. Не постановочная «работа в офисе».
- 1 короткое видео о себе на 10–20 секунд без речи: рабочая сцена, Пхукет, вода или дорога. Использовать как атмосферный фон, без автозвука.
- Podcast Bot: простая схема из четырёх узлов RSS / YouTube / Telegram → бот → MP3 → канал. Скриншот терминала не обязателен.

## Формат описания проекта

Для каждого проекта нужны четыре элемента:

1. Что это: одно прямое предложение.
2. Какую задачу решает: одно предложение без технических терминов.
3. Что сделано лично: интерфейс, логика, разработка, запуск — только подтверждённые пункты.
4. Ссылка на работающий продукт, магазин или GitHub.

Технический стек остаётся короткой строкой для тех, кому это важно. Длинные рассказы о процессе появятся только там, где есть факты и личная история.

## Источники текста

- Void Studio Master Guide: эмоциональная разгрузка + портфолио; «использую технологии как инструмент»; короткий, прямой язык без пафоса.
- Inkfall README: GPU fluid simulation, WebGL2, шесть характеров чернил, синтез звука, реакция на аудио, PNG и запись до 4K.
- Surf README: волна, ветер, прилив и камеры; медиана нескольких моделей; оценка условий и отдельное предупреждение об опасности.
- Poster 2.0 README и паспорт проекта: один выпуск для нескольких площадок, подготовка форматов, расписание, проверка и публикация.
- Argyns README: цифровой реестр 12 родов, статистика, уведомления, города; опубликовано в App Store и Google Play.
- Podcast Bot README: RSS, YouTube и Telegram; MP3, разделение больших файлов, обычная и ускоренная версии.
