# Вариант 1 — сохранённая версия

8 сентября 2026 пользователь положительно оценил эту серию и попросил сохранить все три направления как «Вариант 1». Это зафиксированная точка сравнения, а не окончательно выбранный дизайн.

- A — Воздух: фотографии вокруг личного текста, мягкая реакция на мышь.
- B — Линза: крупная панорама с увеличительным стеклом.
- C — Живое письмо: текст с раскрывающимися изображениями.
- Отдельное портфолио: Inkfall («Чернила и вода»), Surf, визуальные работы.

Полная копия HTML, стилей, сценариев, логотипов и изображений сохранена в этой папке. Локальные ссылки ведут внутри копии. Более новые эксперименты делаются отдельно.

Просмотр с сервера проекта: `/design-archive/variant-1/prototype-personal.html?variant=A` (также B и C).
