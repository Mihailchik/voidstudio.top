# voidstudio.top

Сайт на корне домена `voidstudio.top`. Сейчас — заглушка; наполнение впереди.

Хостинг: Vercel, деплой из ветки `main` этого репозитория.
Заметки по DNS и поддоменам домена живут отдельно, в `~/Trae_PJ/voidstudio.top/DNS.md`.

## Что здесь

```
index.html          заглушка
assets/img/         логотип и иконки
tools/build_media.py сборка витрины работ из библиотеки Poster_2.0
```

Сборки нет: это статические файлы, Vercel отдаёт их как есть.
Локально посмотреть — любой статический сервер:

```bash
python3 -m http.server 4173
```

## Логотип

`assets/img/logo-lockup.png` и `logo-cat.png` — белая заливка на прозрачном фоне.
На странице они подключены через CSS `mask`, поэтому красятся любым цветом
и одинаково работают на светлом и тёмном фоне.

## Витрина работ

`tools/build_media.py` собирает превью, видео и `data/works.json` из библиотеки
проекта Poster_2.0 — того же, что публикует работы в Telegram, Instagram,
YouTube и на Pikabu. Никакие числа на сайте не пишутся руками: количество
работ страница берёт из `works.json`.

```bash
python3 tools/build_media.py --thumbs-only --limit 12   # лёгкий набор
python3 tools/build_media.py                            # всё, ~34 МБ
```

Медиа в репозиторий пока не коммитились — вернутся, когда будет утверждён дизайн.
