# voidstudio.top

Сайт-визитка и портфолио Void Studio на корне домена `voidstudio.top`.

Хостинг: Vercel, деплой из ветки `main` этого репозитория.
Заметки по DNS и поддоменам домена живут отдельно, в `~/Trae_PJ/voidstudio.top/DNS.md`.

## Что здесь

```
index.html           интерактивная лента работ
studio.html          студия, направления и избранные проекты
projects.html        полный список проектов
assets/              стили, сценарии и утверждённые медиа
tools/build_media.py сборка витрины работ из библиотеки Poster 2.0
```

Сборки нет: это статические файлы, Vercel отдаёт их как есть.
Локально посмотреть — любой статический сервер:

```bash
python3 -m http.server 4173
```

## Логотип

`assets/img/logo-lockup.png` и `logo-cat.png` — белая заливка на прозрачном фоне.
На странице они подключены через CSS `mask`, поэтому красятся любым цветом
и одинаково работают на светлом и тёмном фоне.

## Витрина работ

`tools/build_media.py` собирает превью, видео и `data/works.json` из библиотеки
проекта Poster 2.0 — того же, что готовит работы для Telegram, Instagram
и YouTube. Никакие числа на сайте не пишутся руками: количество
работ страница берёт из `works.json`.

```bash
python3 tools/build_media.py --thumbs-only --limit 12   # лёгкий набор
python3 tools/build_media.py                            # всё, ~34 МБ
```

Утверждённые изображения и видео находятся в `assets/gallery/`. Служебные
прототипы, редакторские заметки и инструменты исключены из публикации через
`.vercelignore`.
